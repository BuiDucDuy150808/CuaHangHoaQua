# MayFruit 🍓

## Giới thiệu

MayFruit là website giới thiệu cửa hàng giỏ trái cây nhập khẩu

Đây là dự án mình thực hiện trong quá trình học tập nhằm làm quen với việc xây dựng một website và thực hành những kiến thức đã học

## Công nghệ sử dụng

- HTML
- CSS

## Nội dung website

- Giới thiệu cửa hàng
- Hiển thị các sản phẩm trái cây
- Giới thiệu giỏ quà trái cây
- Thông tin liên hệ
- Một số biểu mẫu cơ bản

## Cách chạy

Tải dự án về máy, mở bằng Visual Studio Code và chạy file `index.html` bằng trình duyệt

## Tác giả

Bùi Đức Duy

Sinh viên năm nhất ngành Công nghệ thông tin
